Static Browser Tool

画像を別形式へすばやく変換

image-shift は HTML / CSS / JavaScript だけで動く完全静的サイトです。GitHub Pages にそのまま配置でき、画像ファイルはサーバーへアップロードされません。

入力はブラウザが読み込める画像形式全般、出力は現在のブラウザがエンコードできる画像形式に対応します。

主な仕様

  • ドラッグ＆ドロップとファイル選択に対応
  • 元画像と変換後の Before / After プレビュー
  • 幅・高さは変更せず、元画像と同じ寸法で出力
  • 品質調整、Lossless モード、透過背景色の指定に対応
